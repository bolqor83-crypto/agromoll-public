# DEMO.md — демо-режим АгроМолл (v0.8.0)

> Как показать приложение «живым» по публичной ссылке: аккаунты, вход,
> сценарии. Датасет — `apps/api/prisma/seed.dataset.ts`, прогон —
> `pnpm --filter @agromoll/api db:seed` (идемпотентен: upsert по phone +
> естественные ключи, повторный запуск не создаёт дублей).

## Вход (SMS-код)

| Среда | Код | Почему |
|---|---|---|
| Dev (локальный стенд, NODE_ENV ≠ production) | **«0000»** | Заглушка без SMS-провайдера (ADR-007) |
| Прод-демо (`AUTH_DEMO_LOGIN=true`, см. ADR-040) | **«0000»** | Явный демо-режим для публичного показа: любой телефон входит по «0000». В логах — предупреждение при каждом коде |
| Прод без `AUTH_DEMO_LOGIN` | случайный 4-значный | Боевой режим: код нигде не показывается, SMS-провайдер ещё не подключён (будущая задача) |

Формат телефона: `+79XXXXXXXXX`.

## Что показывать (сценарии, ~5 минут)

1. **Покупатель (+79000000016)**: лента → фильтр «овощи» → карточка
   «Помидоры розовые» с фото → забронировать → «Мои брони» (новая
   requested + история) → «Долги» (активные и погашенные).
2. **Продавец (+79000000001)**: «Витрина» → лот с фото → «Входящие
   брони» → подтвердить requested-бронь покупателя.
3. **Водитель (+79000000022)**: «Радар» — открытый заказ (картофель,
   100 кг, линия 3 → Западный) → взять → QR-коды pickup/dropoff.
4. **Водитель (+79000000021)**: «Мои часы» — карточка паузы 289-ФЗ с
   парой «линия 5» → «Оспорить блокировку» → апелляция under_review с
   перепиской.
5. **Арбитр (+79000000023)**: очередь споров → кейс «черри, недогруз» →
   переписка сторон → решение; апелляция 289-ФЗ → переписка → решение.

## Демо-данные в цифрах

- 15 продавцов (линии 1–15), 5 покупателей, 2 водителя, 1 арбитр
- 40 лотов (овощи/фрукты/бакалея/снеки/мёд), 15 с фото (picsum.photos,
  внешние URL — S3 для демо не нужен, ADR-038)
- 17 броней: 3 requested, 5 confirmed, 7 completed, 2 disputed
- 8 долгов (6 active, 2 settled — с журналом created/settled)
- 2 спора: under_review (с перепиской) + resolved (favor_buyer)
- 2 блокировки 289-ФЗ (легаси-пара + Виталий↔линия 5) + 1 апелляция
  under_review с перепиской (ADR-035/037)
- 3 доставки: open (радар), assigned, delivered (с журналом и QR)

## Поддержка демо в актуальном состоянии

- Запросы/доставки с TTL со временем гасятся кроном (requested →
  expired, open → expired). Обновить «свежие» статусы — повторный
  прогон сида: `pnpm --filter @agromoll/api db:seed` (на Railway —
  `railway run pnpm --filter @agromoll/api db:seed`, см. runbook v0.8.0-B).
  Сид создаст новые requested-брони, существующие объекты не дублирует.
- Полный сброс демо: очистить БД + `prisma migrate deploy` + seed.
- Фото детерминированы слагом (picsum seed) — картинки стабильны между
  прогонами; это внешние URL, при недоступности picsum клиент покажет
  заглушку, приложение не падает.
