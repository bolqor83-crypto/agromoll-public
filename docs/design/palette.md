# Палитра и обоснование

Дизайн-система описана в [ADR-002](../adr/ADR-002-design-system.md). Ниже — полная
таблица токенов с обоснованием каждого решения. Единый источник истины —
`packages/ui/src/tokens.ts`.

## Принципы

Приложение используют в 4:00–14:00: раннее утро, спешка, улица, перчатки.
Поэтому:

1. **Фон — тёплый нейтральный.** Чисто белый экран в темноте машины или на
   рассвете бьёт по глазам; тёплый молочный `#FAF8F4` сохраняет читаемость без
   «фонарика в лицо».
2. **Акцент — тёмно-зелёный.** Цвет рынка и свежего товара. Спокойный, взрослый,
   не «банковский синий» и не «тревожный красный».
3. **Красный запрещён.** В 4 утра красный читается как «что-то сломалось».
   Срочность передаём мягким янтарным — «обрати внимание», а не «паникуй».
4. **Тёмная тема с первого дня.** Смена начинается в темноте.

## Токены цветов

| Токен | Light | Dark | Назначение |
| --- | --- | --- | --- |
| `background` | `#FAF8F4` | `#151816` | Фон экранов, тёплый нейтральный |
| `surface` | `#FFFFFF` | `#1D211E` | Карточки, поля ввода |
| `surfaceElevated` | `#FFFFFF` | `#242925` | Модалки, меню, иконки-кнопки |
| `primary` | `#2E6B4E` | `#5FB385` | Главные действия, ссылки, «включено» |
| `primaryMuted` | `#E4EFE8` | `#24352B` | Мягкая зелёная подложка (эмодзи-круги, бейджи) |
| `accent` | `#3E8E68` | `#7CC9A2` | Дополнительный зелёный для акцентов |
| `warning` | `#A96E1F` | `#DFAE62` | Срочность БЕЗ тревоги (текст бейджа) |
| `warningSoft` | `#FBF1DE` | `#3A2F1D` | Янтарная подложка бейджа срочности |
| `text` | `#1B241F` | `#F1F4F0` | Основной текст, контраст ≥ 7:1 |
| `textSecondary` | `#4C5850` | `#B7C0B9` | Цены, подписи карточек |
| `textMuted` | `#8B958D` | `#7F897F` | Подсказки, метаданные |
| `border` | `#E7E2D9` | `#2A2F2B` | Границы карточек и полей |
| `onPrimary` | `#FFFFFF` | `#0C1410` | Текст/иконки поверх primary |

В тёмной теме primary светлеет (`#5FB385`), а текст на кнопках становится тёмным —
привычный iOS-паттерн заливки акцентом с инвертированным контрастом.
