# Палитра и обоснование

Дизайн-токены определены в [`packages/ui/src/tokens.ts`](../../packages/ui/src/tokens.ts).
Здесь — почему выбраны именно эти значения. Контрасты посчитаны по WCAG 2.1.

## Условия использования

- 4:00–14:00, спешка, улица, темнота, перчатки, нестабильный интернет.
- Телефон часто держат на весу: экран виден под углом, на ярком утреннем солнце
  или в тёмной кабине машины.
- Пользователь принимает денежные решения: тревожный UI → ошибки → потери.

## Ключевые решения

### 1. Тёплый нейтральный фон, а не чисто белый

- Светлая тема: `background #F7F4EE` («тёплая бумага»), карточки — `#FFFDF9` / `#FFFFFF`.
- Чисто белый (#FFFFFF) на максимум яркости в темноте слепит и «режет» глаза;
  тёплый оттенок снижает нагрузку без потери контраста (текст на фоне — 13.5:1, AAA).
- Тёмная тема: `background #161917` — **тёплый графит без синевы**. Синие тёмные темы
  (типичный «dark mode») в темноте дают цветовые ореолы; нейтрально-зелёный тёплый тон — нет.

### 2. Тёмно-зелёный акцент

- `primary #2D6A4F` — рыночный, спокойный: цвет свежего урожая, весов, кассы.
- Не синий («банк», «документы»), не красный (тревога), не оранжевый (агрессия скидок).
- Контраст кнопки с фоном — 5.8:1 (AA), текста на кнопке — 6.4:1 (AA).
- В тёмной теме primary светлеет до `#7BC496` (контраст с поверхностью 7.7:1, AAA),
  а текст на нём становится тёмным (`onPrimary #0E1F16`, 8.3:1) — инверсия обязательна,
  иначе светлая кнопка с белым текстом нечитаема.

### 3. Мягкий янтарный вместо красного

- Срочность («осталось мало», «новый заказ», «срочно») — `warning #DE911D`
  с прозрачной заливкой (~18%) и глубоким янтарным текстом `onWarning #7C4A0C` (7.3:1, AAA).
- **Красный запрещён**: в 4 утра он считывается как «ошибка», «деньги пропали»,
  «тревога». Янтарный говорит «поторопись», не вызывая стресса.
- Ошибки форм — тоже янтарные (рамка + текст), не красные.

### 4. Типографика и размеры

- `body` — 17/24: базовый размер крупнее дефолтных 14–16 px, читается на ходу.
- `display` — 34/41 для заголовков экрана: роль экрана («Покупатель») видна с первого взгляда.
- Карточка товара: фото → название (`title`) → продавец (`caption`) → цена (`body`, bold,
  primary) → бейдж. Минимум текста, максимум «фото и цифры».

### 5. Геометрия и движение

- Скругления 12–20 px + pill: iOS-like мягкость, никаких «корпоративных» прямых углов.
- Тени: прозрачность ≤ 0.3, радиус 14 — «парящие» карточки без жёстких границ.
- Тач-зоны от 48×48 (кнопки 48/56 px, переключатель темы 48 px + hitSlop).
- Анимации 200–300 мс, spring (Reanimated): нажатие кнопки «проседает» до 0.97
  и возвращается пружиной — тактильная отдача на ключевых действиях.

## Таблица контрастов (WCAG 2.1)

| Пара                               | Светлая    | Тёмная     |
| ---------------------------------- | ---------- | ---------- |
| text / background                  | 13.5:1 AAA | 15.1:1 AAA |
| text / surface                     | 14.5:1 AAA | 13.6:1 AAA |
| textSecondary / surface            | 6.8:1 AA   | 8.1:1 AAA  |
| primary / background (кнопка)      | 5.8:1 AA   | 7.7:1 AAA  |
| onPrimary / primary (текст кнопки) | 6.4:1 AA   | 8.3:1 AAA  |
| onWarning / surface (бейдж)        | 7.3:1 AAA  | 11.6:1 AAA |
