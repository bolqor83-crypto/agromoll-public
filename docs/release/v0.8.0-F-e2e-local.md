# v0.8.0-F — Локальный E2E-стенд: полный пользовательский флоу

> Дата: 2026-11-07. Прогон всех флоу через Playwright (headless Chromium)
> против полного стека в среде агента. Скриншоты и видео:
> `docs/screenshots/v0.8.0-local/` (36 скриншотов + видео цикла покупателя).

## Стенд (без docker/root)

| Компонент | Как поднят |
|---|---|
| Postgres 17.11 + PostGIS 3.5 | `.deb` Debian 13 (apt-get download + dpkg -x) в `/tmp/pg`, кластер `/tmp/pgdata`; control-файл `postgis.control` — алиас `postgis-3.control` (в PG17+ расширение версионируется) |
| Redis 8.0 | тот же способ (`redis-server` + `liblzf1`) |
| API (NestJS) | `node apps/api/dist/src/main.js`, NODE_ENV=development (код «000000»), JWT-заглушки локальные |
| Web (Expo export) | `EXPO_PUBLIC_API_URL=http://127.0.0.1:3000 npx expo export --platform web --output-dir dist-e2e`; отдаёт `scripts/serve-expo.py` (Vercel-подобный fallback `/auth → auth.html`) |

Подъём: `bash scripts/local-stack-start.sh` + `bash scripts/e2e-stand-up.sh`
(агентская среда; между вызовами песочница прибивает слушающие процессы,
поэтому web-сервер стартует в одном вызове с прогоном). Миграции —
`prisma migrate deploy`, затем `db:seed` (двойной прогон — 0 дублей,
идемпотентность сида подтверждена).

## Найденные и исправленные баги (5)

Подэтап F сделал то, ради чего существует: поймал реальные баги до пуб­
ликации. Каждый исправлен в этом же подэтапе (правило «не переходи к G
с багами»).

1. **`start`-скрипт API указывал на несуществующий путь** — `node
   dist/main.js`, тогда как сборка кладёт бинарь в `dist/src/main.js`
   (никто не замечал: dev-режим работает из исходников, e2e стартует
   модуль напрямую). При первом же запуске стенда `node dist/main.js`
   упал с MODULE_NOT_FOUND. Исправлены `apps/api/package.json` (`start`)
   и `railway.json` (`startCommand`) — иначе Railway-деплой из
   подэтапа B упал бы тем же образом.
2. **Код-заглушка не проходила маску ввода**: API выдавал 4-значный
   «0000» (DEV_CODE), UI принимает только 6 цифр (CODE_LENGTH=6) —
   вход в dev/демо через UI был НЕВОЗМОЖЕН (e2e-тесты API не ловили:
   они не ходят через UI). DEV_CODE = «000000» (шесть нулей), обновлены
   все тексты/тесты/доки. Прод-демо (AUTH_DEMO_LOGIN) использует его же.
3. **Seed не проставлял резерв листингам** — TTL-крон не мог погасить
   просроченную requested-бронь (`releaseReservation`: WHERE
   quantityReserved >= qty → 409 в логах каждые 30 с, брони «зависали»).
   Теперь сид инкрементирует quantityReserved (активные брони) и
   уменьшает quantityAvailable (completed), как это делает боевой код.
4. **`/work-hours/open-session` с пустым ответом валил экран «Часы»** —
   Express-адаптер Nest сериализует null-ответ контроллера в ПУСТОЕ тело
   (res.send(null) → Content-Length: 0), axios парсит его как `''`, zod-
   валидация падала → «Данные пришли в неожиданном формате». Экран часов
   был недоступен водителю без открытой смены (и на web, и на native —
   тот же axios). Клиент теперь трактует пустое тело как «нет сессии»;
   +3 юнит-теста (пустое тело / json-null / мусор → INVALID_RESPONSE).
5. **Блокировка 289-ФЗ была невидима в «Часах»** — пара 021↔линия 5 не
   имела monthlyPairTotal, а экран строится по ним; сид теперь создаёт
   месячный итог (61 ч — переработка), карточка паузы с апелляцией
   видна. Плюс: сид-доставки пересоздаются, если TTL-крон погасил
   открытую (гейт по активным статусам, а не по всем).

Также: `eslint.config.js` — игнор `dist-e2e/**` (артефакты стенда),
`.gitignore` — dist-e2e/.

## Ограничения стенда

- **S3-зависимые e2e (доказательства споров, фото через presigned)**
  локально не гоняются — LocalStack требует docker; в CI они выполняются
  с сервис-контейнером (v0.7.0-B). Локально: 101/112 e2e-тестов зелёные,
  11 S3-зависимых пропущены по среде (не по коду) — CI подтвердит.
- **QR-скан камерой** — native-only; на web по дизайну ADR-015 ручной
  ввод кода (проверено: сверка «Код совпал»).
- Версии стека: Postgres 17 + PostGIS 3.5 + Redis 8 против CI-образов
  16/3.4/7 — те же миграции, расхождение только в минорных версиях.
- Троттлер `/auth/request-code` (1 запрос/60 с на телефон) — флоу
  разведены по разным аккаунтам; перед итеративными прогонами API
  перезапускается (счётчик in-memory).

Скрипты стенда — агентская среда: `scripts/local-stack-start.sh`,
`scripts/e2e-stand-up.sh`, `serve-expo.py`, `e2e_local.py` (Python +
Playwright; копия — `docs/release/v0.8.0-F-e2e-local.py.txt`).
