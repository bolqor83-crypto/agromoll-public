# v0.8.0-D — Runbook: EAS Build (сборка .apk)

> Статус: **ждёт EXPO_TOKEN** (стоп-правило №1). Готово: `apps/mobile/eas.json`
> (профили preview/production), ADR-041. Выполнить сразу после передачи
> токена. Сборка занимает 10–20 минут (первая — дольше: прогрев кэша).

## 0. Предусловия

- `EXPO_TOKEN` (expo.dev → Account Settings → Access Tokens).
- API задеплоен на Railway (подэтап B) — иначе в бандл вшьётся
  PLACEHOLDER и приложение покажет «Сервер не настроен».
- Apple Developer аккаунта нет → iOS пропускаем (стоп-правило №5),
  задокументировано в ADR-041.

## 1. Подготовка (один раз)

```bash
npm i -g eas-cli
eas login --token $EXPO_TOKEN
cd apps/mobile
# создаст проект на expo.dev, впишет extra.eas.projectId в app.json:
npx eas init
```

`eas init` добавит в `app.json`:
```json
"extra": { "eas": { "projectId": "<uuid>" } }
```
Зафиксировать projectId коммитом (нужен также для OTA, ADR-042).

## 2. URL API в профиле сборки

Заменить `PLACEHOLDER_API_URL` в `apps/mobile/eas.json` (оба профиля) на
публичный домен Railway из подэтапа B, например
`https://agromoll-api-production-XXXX.up.railway.app`, закоммитить.

Альтернатива без правки файла — переменные окружения EAS:
```bash
eas env:create --name EXPO_PUBLIC_API_URL \
  --value https://agromoll-api-production-XXXX.up.railway.app \
  --environment production
# и удалить блок "env" из профиля preview в eas.json
```

## 3. Сборка preview (.apk, internal distribution)

```bash
cd apps/mobile
npx eas build --platform android --profile preview --non-interactive
```

Дождаться статуса **Succeeded**, забрать install URL (виден в выводе CLI
и на expo.dev → Build → … → Install; рядом QR для телефона).

## 4. Проверка .apk

1. Установить по ссылке на Android-устройство/эмулятор.
2. Войти: телефон демо-покупателя `+79000000016`, код `0000`
   (AUTH_DEMO_LOGIN=true на проде, DEMO.md).
3. Убедиться, что лента лотов живая (не localhost и не «Сервер не
   настроен»): открыть карточку с фото → забронировать.
4. Камера QR (радар водителя `+79000000021`) — разрешение камеры спрашивает.

## 5. iOS (пропущено — нет Apple Developer)

Для включения: Apple Developer $99/год → `npx eas build --platform ios
--profile preview` → internal distribution по UDID. Подробности и цена
перехода на TestFlight — ADR-041.

## 6. Частые ошибки

- «Config error app.json» — обычно невалидный JSONC в eas.json/app.json
  (eas.json поддерживает комментарии, app.json — нет).
- Сборка упала на «PLACEHOLDER_API_URL» — пропущен шаг 2.
- «Credentials are not set up» — для preview-apk не требуется (debug
  keystore EAS создаёт сам); для app-bundle спросит store credentials.
