# ADR-024: Клавиатура, персист темы и скругления модалок

- Статус: **Принято**
- Дата: 2026-11-06
- Этап: v0.6.1 «Mobile UX Excellence» (подэтап B)

## Контекст

Три долга из инвентаризации mobile-опыта:

1. **KeyboardAvoidingView отсутствовал** — инпут «Комментарий» в листе
   приёмки (y=653/844) перекрывался клавиатурой на реальном устройстве.
   Экран входа (телефон/код) — та же проблема.
2. **Тёмная тема не персистилась** — после перезагрузки всегда системная,
   выбор пользователя терялся.
3. **SheetModal без верхних скруглений** — резкий верхний край листа;
   фон листа не задан явно (контент просвечивал scrim).

## Решение

### Клавиатура — системный KeyboardAvoidingView, не библиотека

`src/lib/keyboard.ts` — чистая функция `resolveKeyboardBehavior(os)`:

- **iOS: 'padding'** — контент поднимается над клавиатурой;
- **Android: 'height'** — внутри `Modal` системный adjustResize не
  срабатывает (окно модалки не ресайзится), 'height' страхует;
- **Web: undefined** — физической клавиатуры-оверлея нет, KAV выключен.

Почему не `react-native-keyboard-aware-scroll-view`: ещё одна зависимость
(+КБ в бандл), а нужное дают системные примитивы — KAV (SheetModal, вход)
и `automaticallyAdjustKeyboardInsets` (iOS 15+, авто-скролл к активному
инпуту внутри листа). ScrollView листа уже имел
`keyboardShouldPersistTaps="handled"`.

Применение: экран входа обёрнут целиком; SheetModal — обёртка для ВСЕХ
шести модальных форм (создание лота, запись долга, корректировка,
подтверждение+комментарий, моя точка, заказ доставки) — один фикс закрывает
все формы сразу.

### Персист темы — zustand persist + платформенный storage

`src/store/theme.ts` подключает `persist` из zustand/middleware.
Хранилище — `src/lib/preferences-storage.ts`: native —
`@react-native-async-storage/async-storage` (стандартный key-value;
тема — не секрет, SecureStore не нужен), web — `localStorage` (как токены
и outbox: web — демо-платформа, ADR-006/007). Ключ `agromoll.theme`,
версия схемы 1.

Семантика: сохранённый выбор важнее системной схемы; тумблер пишет
мгновенно (persist сериализует каждое set). Гидрация асинхронная — до её
завершения рендерится 'system' (один кадр при старте на native).

### SheetModal

- `borderTopLeftRadius/borderTopRightRadius = radius.lg` (20, ADR-002)
  + `overflow: 'hidden'` — контент не вылезает за скругления;
- явный `backgroundColor: colors.background` — раньше фон листа не был
  задан, текст рендерился прямо на затемнении (заодно закрыто);
- `keyboardVerticalOffset={0}` + behavior из общего хелпера.

### Прочие долги

- **Иконки**: icon/splash/favicon перегенерированы в геометрии
  дизайн-системы (рыночный навес с фестонами + ящик; тёплый крем
  #F7F4EE, зелёный #2D6A4F, акцент #40916C) — без текста и стоковых
  картинок. Splash — прозрачный PNG со знаком, фон задаёт app.json.
- **Дубль boot-лога**: React 18 в dev монтирует эффекты дважды —
  модульный флаг `bootLogged` в root layout гарантирует одну запись.

## Тесты

- `theme.test.ts`: тумблер пишет в хранилище сразу; пере-импорт стора
  («перезапуск») восстанавливает выбор; без записи — 'system'.
- `keyboard.test.tsx`: все три платформенные стратегии; SheetModal
  рендерит контент формы внутри KAV; закрытый лист не рендерится;
  радиус из токена = 20.
- Живая проверка: localStorage `agromoll.theme` появляется после тумблера,
  после перезагрузки тема восстанавливается (проверено в браузере).
